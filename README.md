# 🌱 LoopList – Habit Tracker with Social Accountability

LoopList is a simple and intuitive habit-tracking application built using React. The goal is to help users build better habits through structured routines and community accountability.

> ⚠️ Note: Backend functionality using Supabase and PostgreSQL is planned but not yet implemented. Currently, the app works with static mock data and front-end state management.

---

## 🖥️ Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Icons**: Lucide-React
- **Routing**: React Router DOM
- **State Management**: React Context API
- **Planned Backend**: Supabase (Auth + Database), PostgreSQL

---

## 🚀 Features

- 🗂️ **Explore Public Loops** categorized by frequency
- 🔍 **Search Functionality** to filter loops by title or emoji
- 🧠 **Loop Detail View** to understand the purpose and schedule
- 🧾 **Create New Loop** (UI only)
- 🙋 **Profile Page** (Static for now)
- 🔐 **Login & Signup Pages** (UI ready for future integration)
